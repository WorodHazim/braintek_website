# CMS guide

The site uses structured Strapi content rather than a free-form page builder. Strategic pages remain design-controlled while reusable records feed services, sectors, platforms, insights, team, partners, CTAs, FAQs, and form options.

The BRAINTEK Operations menu item in Strapi provides an inquiry dashboard. The native Content Manager remains the source of truth for content editing.

Recommended editorial states: Draft -> Review -> Published -> Archived. Strapi draft/publish is enabled on strategic content types. Use review ownership and permissions operationally before production publishing.
